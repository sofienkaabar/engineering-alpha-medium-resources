# Does a Bullish Engulfing Candle Need Fresh Ground?

I run this standalone file with Python 3.11:

```powershell
python -m pip install numpy==1.26.4 pandas==2.3.3 requests==2.34.2
python experiment.py
```

I need an internet connection. I print the numerical results in the terminal and keep the downloads in memory. I save no data, charts, article text or reports.

I charge 0.1% on the next-open purchase and hypothetical exit for each event. I report conditional trade outcomes, not a compounded portfolio.

I use the fixed markets and periods stated in the script. I may get revised numbers if a public source updates its historical records.
