# Does a Time Stop Improve a Donchian Breakout Strategy?

I test this idea with my standalone `experiment.py`. I use Python 3.11. I install the packages and run it from this folder:

```powershell
python -m pip install numpy==1.26.4 pandas==2.3.3 requests==2.34.2
python experiment.py
```

I need an internet connection for the daily prices. I print my numerical comparisons in the terminal; I do not save article text, images, data or reports.

I charge 0.1% on each actual purchase and sale, including my passive comparison. I use completed information and next-open execution, and I liquidate at the final evaluation opening. I assign zero return to idle cash. I measure drawdowns at openings.

I evaluate January 3, 2017 through November 6, 2026, with an additional later chronological comparison. I use earlier history for indicator warm-up or model training. I treat these as retrospective research results, not a genuinely unseen holdout or a promise of future returns.

I may obtain slightly different numbers if the price provider revises its historical adjustments.
