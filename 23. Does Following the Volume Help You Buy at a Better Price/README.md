# Does Following the Volume Help You Buy at a Better Price?

I run my standalone calculation with Python 3.11:

```powershell
python -m pip install numpy==1.26.4 pandas==2.3.3 requests==2.34.2
python experiment.py
```

I need an internet connection. I print my comparisons in the terminal and keep the downloaded data in memory. I create no article, chart, data or report files.

I use a small-order price replay with a five-basis-point fee and a three-basis-point modeled spread/slippage allowance. I do not claim executable quotes or market impact. I print zero-volume and participation diagnostics because a completed bar does not guarantee a fill.

I keep the markets, periods and rules fixed in the script. I may see revised results if historical records change.
